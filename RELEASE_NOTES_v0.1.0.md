# TCHLauncher v0.1.0

Primera versión local para Windows. Permite crear servidores Vanilla y Paper, descargar Java compatible, iniciar y detener procesos, consultar la consola, editar configuración, hacer copias de seguridad e importar servidores existentes.

La interfaz usa una barra lateral con imágenes de servidor elegidas desde un archivo PNG, JPG o WebP. La imagen puede añadirse al crear o importar un servidor y cambiarse o quitarse después desde Configuración.

## Requisitos y límites

- El instalador de Windows todavía no está firmado digitalmente.
- La descarga de Java y de los archivos del servidor requiere internet. Los servidores y sus datos se ejecutan y almacenan localmente.
- Fabric, NeoForge, mods, plugins, jugadores, mundos, red pública y tareas programadas siguen pendientes. Consulta `NEXT_TODOS.md`.
- La experiencia visual nativa aún requiere una revisión manual en varias resoluciones.
