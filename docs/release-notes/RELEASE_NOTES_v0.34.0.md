# TCHLauncher 0.34.0

## Content management

- Browse installed files in pages of 24 while searching and filtering the full
  inventory. Only the displayed page reads icons; hidden views pause those reads.
- Keep installation plans, their type and compatible versions together. Failed
  replacement preserves the previous review; obsolete responses cannot replace it.
- Share operation ownership and locking across installs, removal, enable/disable
  and metadata recovery, retaining each operation's existing error handling.
- Recognize Windows Paper plugin errors after repeated console prompts and ANSI
  formatting. Retain bounded recent diagnostic evidence and the latest error.
- Translate content diagnostic counts, dates, file labels and dependency alternatives
  when English is selected. Original Minecraft log evidence remains unchanged.

## Recovery and efficiency

- After a completed Minecraft upgrade, show metadata read failure separately and
  offer a read-only retry. Block new plans until server metadata is refreshed.
- Keep update warnings visible even if subsequent startup halts or cannot be verified.
- Pause hidden network observations and serialize visible reads. Native router lease
  maintenance remains independent.
- Preserve console row identities at the retained-log limit and share clock formatting.
- Remove unused artwork, duplicate error formatting and obsolete interface CSS.
- Limit development artifacts by disabling debug symbols and incremental caches.
  Compiler caches are regenerable build files, not the installed application.

## Verification boundaries

All 124 frontend tests and TypeScript pass. Real engine evidence recorded since the
previous preview includes Vanilla world conversion/complete rollback and a
Fabric/Lithium world-plus-content export/import boot. These isolated checks do not
prove native UI interaction, client gameplay or physical router behavior.

The full original manager objective remains open. Native install/upgrade/uninstall,
visual/keyboard/screen-reader QA and actual internet-player connections remain
pending. Reported friend-hosted RAM, missing-mod, Minehut identity and internet-stall
cases still require evidence from that host. Linux and client launching remain deferred.
