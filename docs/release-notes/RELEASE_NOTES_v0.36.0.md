# TCHLauncher 0.36.0

## Complete Paper world imports

- Detect adjacent Nether and End folders when selecting a Paper world. Creation
  and World Manager show every source/destination name and the total family size.
- Rename and copy the reviewed family together, preserving the originals. Repeat
  dimension detection before copying and reject changed selections, unsafe folders
  and occupied destinations. Stop the source server before copying its files.
- Require Paper for split Paper dimensions; there is no automatic conversion to
  Vanilla, Fabric or NeoForge. Single-folder worlds keep their ordinary import path.
- Use staged copying and trusted publication recovery for imports as well as
  duplicate/export. Interrupted publication preserves conflicting or modified files.
- Update the archive README to explain the reviewed import instead of manual
  sibling-folder copying.

## Release notes by project

- Show available author notes for every changed mod/plugin and required dependency
  in a bulk review. Individual reviews retain notes for the complete planned set.
- Identify the exact version and explicitly label missing notes. Note bodies mount
  only while their disclosure is open and remain plain text in a scrollable region.
- Retain the existing reviewed-plan, compatibility and backup requirements.

## Whitelist identities

Whitelist removal now follows the selected UUID instead of its name. It requires
a stopped server, preserves unrelated records and unknown fields, and retains an
original-byte safety copy. Removing an absent UUID writes nothing; invalid or
corrupt lists are preserved. The old name-based removal action was retired.

## Verification boundaries

Real Paper 1.21.4 passed five sessions, including backup/restore and a populated
three-dimension folder export/import into another instance. All 45 world-file
hashes matched before target boot. Minecraft commands verified distinct saved
blocks in Overworld, Nether and End after boot, without placing new target blocks.
The source/export stayed unchanged and no default replacement world was generated.
The existing test scenario was extended without increasing the retained test count.

Frontend contract checks and React render fixtures cover review filtering,
dependencies, translated labels, escaping and family destination names. These are
not native interaction or layout checks. The other eight real-engine scenarios
were not rerun for this milestone.

The full manager objective remains open. Native visual/keyboard/screen-reader
review, clean install/upgrade/uninstall, client gameplay and physical router/Internet
checks are pending. Reported friend-hosted RAM, missing content, identity and
connection stalls still need evidence from the affected host. Power-loss recovery
is not proven by simulated interruption checks. Linux and client launching remain
deferred. No new dependency was added.

This is a local unsigned Windows preview. Building it does not install the app or
publish a GitHub release.
